# Welcome Boiler Robotics

This book is a knowledge base for the software team.
The code is separated into 3 repositories.

- [rover-code](https://github.com/boilerrobotics/rover-code) contains every code that runs on the rover, for example, motor control or camera.
- [base-station](https://github.com/boilerrobotics/base-station) contains code that runs on the base station, for example, remote operation control.
- [telemetry](https://github.com/boilerrobotics/telemetry) contains web application for the telemetry.
